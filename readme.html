硬幣價格練習

給孩子練習台幣硬幣計算的網頁遊戲，支援手機、平板與電腦操作。

功能特色

  • 兩種練習模式：看價格付錢、數硬幣總價。
  • 三種金額範圍：100 以內、200 以內、500 以內。
  • 硬幣面額包含 50、10、5、1 元。
  • 50 元為黃銅色最大，10 元與 5 元為銀色，1 元為古銅色最小。
  • 可點一下硬幣放入付款盤，也可以拖曳硬幣到付款盤。
  • 放錯硬幣時，可點一下付款盤中的硬幣移除，或拖出付款盤。
  • 答對、答錯會播放不同音效。
  • 顯示連續答對、答對總數、答錯總數。
  • 可重新計分。
  • 支援 PWA，可加入 iPad 或手機主畫面使用。

金額範圍

  • 100 以內：1 到 99。
  • 200 以內：100 到 199。
  • 500 以內：1 到 499。

使用方式

直接用瀏覽器開啟 index.html，或部署到 GitHub Pages、Netlify、Cloudflare Pages 等靜態網站服務。

部署到 GitHub Pages

  1. 建立一個新的 GitHub Repository。
  2. 將本專案所有檔案上傳到 repository 根目錄。
  3. 到 repository 的 Settings。
  4. 選擇 Pages。
  5. 在 Build and deployment 中選擇 Deploy from a branch。
  6. Branch 選擇 main，Folder 選擇 /root。
  7. 儲存設定，等待 GitHub Pages 完成部署。

在 iPad 或手機加入主畫面

iPad / iPhone

  1. 用 Safari 開啟遊戲網址。
  2. 按分享按鈕。
  3. 選擇「加入主畫面」。
  4. 名稱可設定為「硬幣練習」。

Android

  1. 用 Chrome 開啟遊戲網址。
  2. 按右上角選單。
  3. 選擇「加入主畫面」或「安裝應用程式」。

離線使用

本專案包含 service-worker.js。部署到 HTTPS 網站後，瀏覽器會快取遊戲檔案。第一次開啟需要網路，之後通常可以離線使用。

技術說明

  • 純 HTML、CSS、JavaScript。
  • 不需要後端伺服器或資料庫。
  • 支援 Pointer Events，滑鼠、觸控、平板都可使用。
  • 已設定 PWA manifest 與 service worker。
